# Design screens

Static HTML on `src/ui/tokens.css`, written before the app was ported to the design system and kept as
the reference for how each screen should look: unlock, account, send and its recipient checks,
receive, activity, settings, duress, the dapp browser with the approval sheet, the extension popup
and the approval window. Open any file in a browser, or render them all at phone width in light and
dark with `node scripts/design-shots.mjs` (needs the Playwright install named in the script).
